# USIU Clinic Front-end

A responsive multi-page HTML/CSS/JavaScript front-end based on your original USIU Clinic design. The navy/blue/yellow palette, DM Sans + Manrope typography, cards, forms, dashboards and hero layout have been retained.

## Pages
- `index.html` — Home
- `login.html` — Login
- `register.html` — Registration
- `patient-dashboard.html` — Patient dashboard
- `book-appointment.html` — Appointment request
- `appointments.html` — Appointment history
- `doctor-dashboard.html` — Doctor dashboard
- `admin-dashboard.html` — Admin view

## Run locally
Open `index.html` in a browser, or use VS Code Live Server. Keep the folder structure intact so the CSS and JavaScript links work.

## Important integration note
The booking form currently performs browser-side validation only. It does not save data or send an appointment request. Connect it to your team's approved backend/API before using real patient information. Login, registration and dashboard data also require backend authentication and data integration. Do not put real patient information in this demo.
